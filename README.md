🏪 Jenson USA Sales, Inventory &amp; Customer Analysis | SQL Project

📌 Project Overview

The Jenson USA SQL Analysis Project is a comprehensive data analytics project focused on uncovering actionable business insights from an e-commerce retail dataset using advanced SQL techniques.

This project analyzes sales performance, customer purchasing behavior, staff productivity, store efficiency, and inventory management to help improve operational strategy and support data-driven decision-making.

By working with relational datasets across multiple business functions, this project demonstrates how SQL can transform raw transactional data into strategic business intelligence.

🎯 Business Objective

E-commerce businesses generate large volumes of transactional and operational data daily. Without structured analysis, it becomes difficult to:

Identify best-selling products and categories Understand customer retention and repeat purchasing behavior Evaluate staff and store performance Optimize inventory management Detect revenue-driving trends ✅ Solution:

This SQL project provides a structured analytical framework to extract, clean, and analyze business-critical data for better strategic planning.

🗂️ Dataset Overview

The project uses a multi-table relational database containing customer, product, sales, and operational data.

Key Tables Included: 👥 customers

Customer demographics and account information.

🛒 orders

Order-level transaction records.

📦 order_items

Detailed product-level purchase data for each order.

🏷️ products

Product catalog including categories, pricing, and stock details.

👨‍💼 staffs

Employee performance and sales responsibility data.

🏬 stores

Store locations and operational details.
